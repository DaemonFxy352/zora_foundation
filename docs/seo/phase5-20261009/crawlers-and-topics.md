# Crawl access and topic coverage — 2026-10-09

No crawler permissions changed. [Live observations](live-crawl-baseline.json) show `User-Agent: * / Allow: /`, a working sitemap, and `index, follow` on the three sampled public pages without an X-Robots-Tag restriction. This is ordinary public access, not evidence that requests from every provider's real IP range pass its network/security controls. Protected Vercel previews still require authorized access; their noindex configuration is unchanged. Missing routes return 404 and noindex, including internal materials. Robots rules are not a confidentiality boundary.

The existing wildcard rule does not opt out of training crawlers. That is a recorded preexisting policy, not a new approval. The owner must explicitly decide any training-policy change. No firewall allowance, authentication bypass, robots change, cache change or platform setting was made. Allowing retrieval does not guarantee indexing, inclusion or citation.

`llms.txt` is an optional, concise navigation convention ([proposal](https://llmstxt.org/)), not an established ranking factor or access policy. Google states that additional AI files and special schema are not required for its AI search features. Our directory links only built canonical public pages and explains that research and workshops are planned. It includes no reports because the publication registry is empty. It does not substitute for HTML, robots rules, source citations, or publication approval.
